# Releases ⭐

Releases mark milestones in your project's life. They combine Git tags with human-readable notes, binaries, and auto-generated changelogs to communicate what changed to end users.

## Setup

This lesson is conceptual. No sandbox is required.

## Step-by-step task

1. Navigate to a repository with published releases (e.g., `cli/cli`).
2. Click the **Releases** tab on the right side.
3. Select a recent release and read its notes.
4. Note any attached assets (binaries, checksums).
5. Switch to the **Tags** page and compare it with the **Releases** page.
6. Read GitHub's documentation on auto-generated release notes.
