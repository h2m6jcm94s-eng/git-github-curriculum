# Reviews and Suggestions ⭐⭐

Code review is more than saying "LGTM". GitHub's review tools let you request specific changes, suggest exact code edits, and enforce required approvals before merge.

## Setup

This lesson is conceptual. No sandbox is required.

## Step-by-step task

1. Open any open PR on GitHub and go to the **Files changed** tab.
2. Hover over a line of code and click the blue **+** icon.
3. Choose **Start a review** (or **Add single comment**).
4. In the comment box, click the **±** icon (Suggest changes) and type a replacement line.
5. Add a general comment in the "Review summary" box.
6. Submit the review as **Comment**, **Approve**, or **Request changes**.
7. Think about which state you would use for a PR that has a minor typo versus one with a fundamental design flaw.
