# gh Issue Ops ⭐

Issues track bugs, features, and tasks. The `gh issue` commands let you create, search, update, and discuss issues without switching contexts.

## Setup

Run the setup script to create a local repo context:

```bash
bash setup.sh
```

## Task

1. Create a new issue with a title and body.
2. Assign the issue to yourself (or another user).
3. List open issues and view a specific issue.
4. Close the issue and add a closing comment.

## ❓ Normal question

How do you create an issue and assign it?

## 🔥 Tricky question

You closed an issue by mistake with `gh issue close`. Can you reopen it from the CLI?

## ✅ How to check yourself

Run `gh issue list --state closed` and verify your issue appears.
